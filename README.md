# Fake News Detection System

A Machine Learning based Fake News Detection web application built using Python, Flask, and Scikit-learn.  
This project predicts whether a news article is **Real** or **Fake** using Natural Language Processing (NLP) techniques.

---

## 🚀 Features

- Detects fake and real news articles
- Machine Learning based prediction
- User-friendly web interface using Flask
- Text preprocessing and vectorization
- Trained model stored using Pickle
- Fast and lightweight application

---

## 🛠️ Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML/CSS
- Pickle

⚙️ Installation

1️⃣ Clone the Repository
git clone https://github.com/chandan-st/Fake-News-Detection.git

2️⃣ Navigate to Project Folder
cd Fake-News-Detection

3️⃣ Create Virtual Environment
python -m venv venv

4️⃣ Activate Virtual Environment
Mac/Linux
source venv/bin/activate
Windows
venv\Scripts\activate

5️⃣ Install Dependencies
pip install -r requirements.txt
▶️ Run the Application
python app.py
The application will start on:
http://127.0.0.1:5000
