# Fake News Detection System

A Machine Learning based Fake News Detection web application built using Python, Flask, and Scikit-learn.  
This project predicts whether a news article is **Real** or **Fake** using Natural Language Processing (NLP) techniques.

---

## 🚀 Features

- Detects fake and real news articles
- Machine Learning based prediction
- User-friendly web interface using Flask
- Text preprocessing and vectorization
- Trained model stored using Pickle
- Fast and lightweight application

---

## 🛠️ Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML/CSS
- Pickle
